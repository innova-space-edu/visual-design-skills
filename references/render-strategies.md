# Render strategies

## Deterministic
SVG, HTML/CSS, canvas, LaTeX, Vega-Lite, GeoJSON/MapLibre, CAD-like primitives. Use when correctness is measurable.

## Generative
Diffusion/image model creates the pixels. Use for appearance-centric visuals.

## Hybrid
Deterministic structure is authoritative; generative assets are placed into or around it. Use for most educational infographics, illustrated maps, technical presentations, and text-heavy posters.
