# Typography

For short text integrated into an image:
- quote exact wording
- specify hierarchy and relative size
- specify placement/alignment
- specify visual family rather than relying on an unavailable exact font

For long text, tables, formulas, worksheets, instructions, or legal/technical copy:
- typeset deterministically in SVG/HTML/LaTeX
- use generated imagery only as decoration or illustration

QA must compare exact visible text with the source string.
