# advertising-creative

## Default strategy
hybrid

## Activate for
- display ads
- social ads
- campaign key visuals
- promotional creative

## Workflow
1. Read the normalized VisualBrief.
2. Identify authoritative elements and editable elements.
3. Apply the specialist rules.
4. Produce a render/edit plan with acceptance criteria.
5. Run visual-quality-control after rendering.

## Specialist rules
- Define one primary communication goal.
- Keep product/offer hierarchy clear.
- Reserve exact copy for deterministic typesetting.
- Generate aspect-ratio variants from a shared composition system.

## QA focus
- message hierarchy
- brand fidelity
- CTA visibility
- variant consistency
