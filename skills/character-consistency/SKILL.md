# Character Consistency

Build a character sheet before a multi-image sequence when possible:
- face/head shape
- age presentation
- hair
- eyes
- skin/fur/material
- height/proportions
- signature clothing
- accessories
- color keys
- forbidden drifts

For every frame, distinguish immutable traits from scene-specific traits.
Use pose/reference controls when available.
