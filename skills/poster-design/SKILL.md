## Required workflow
1. Read the VisualBrief and preserve explicit user constraints.
2. Apply the specialist rules below.
3. Use the router-selected backend and relevant references.

## Specialist rules

- Headline must remain the primary reading entry unless specified otherwise.
- Reserve bleed/safe area for print.
- Use generated image as hero layer when text is exact.
