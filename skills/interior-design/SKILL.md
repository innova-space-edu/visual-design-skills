# interior-design

## Category
architecture

## Default render strategy
hybrid

## Activate when
Create interior-design concepts and renders with coherent circulation, furniture scale, materials, lighting, and spatial continuity.

## Required workflow
1. Read the VisualBrief and preserve explicit user constraints.
2. Apply the specialist rules below.
3. Use the router-selected backend and relevant references.
4. Return generation/render instructions plus acceptance criteria.
5. Run visual-quality-control after rendering.

## Specialist rules
- Respect room dimensions when supplied.
- Do not block circulation paths.
- Keep furniture scale plausible.
- Distinguish concept render from technical plan.

## QA focus
- circulation
- scale
- furniture placement
- materials
- lighting
